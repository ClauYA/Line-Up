**Lineup **
The Waitlist That Texts Your Customers

A text-based waitlist system for barbershops, counters, and walk-in businesses. No apps, no hardware — just text.

**About**

Lineup eliminates crowded waiting areas and inefficient queue management. Customers join the line by text, see their spot, and get pinged when they're up — so they wait at the coffee shop, not in your doorway.

This is a responsive landing page showcasing the product features, pricing, and user testimonials.

**Features**

- **Responsive Design**: Mobile-first approach with hamburger menu
- **Interactive FAQ**: Accordion-style expandable questions
- **Smooth Navigation**: Anchor links to page sections
- **Modern UI**: Clean typography with Inter and Instrument Serif fonts
- **Accessible**: Semantic HTML and ARIA labels
- **No Dependencies**: Pure HTML, CSS, and vanilla JavaScript

**Technologies**

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript
- Google Fonts (Inter, Instrument Serif)
